# Dataverse Schema Artifacts

The subdirectories in this folder (`tables/`, `connection-references/`, `environment-variables/`) are placeholders reserved for future Dataverse solution export artifacts.

The operational Dataverse schema is deployed programmatically via:

- `scripts/create_dataverse_schema.py` — Tables and columns
- `scripts/create_environment_variables.py` — Environment variables
- `scripts/create_connection_references.py` — Connection references

See `docs/SCHEMA.md` for the complete schema reference.
