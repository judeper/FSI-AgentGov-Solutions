# Evidence Export

> **Status:** Stub — Evidence export documentation will be added in Phase 4.

## Overview

The Content Moderation Monitor will support exporting tamper-evident JSON evidence packages for regulatory examinations, following the same pattern as the Agent Access Monitor.

## Planned Features

- Zone-based filtering (All/1/2/3)
- Date range support
- SHA-256 companion hash files
- Interactive and certificate-based authentication modes
