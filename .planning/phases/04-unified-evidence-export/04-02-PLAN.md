# Plan 04-02: Evidence Integrity Verification Script

## Objective
Create `Test-UnifiedEvidenceIntegrity.ps1` — verifies an exported evidence package by recalculating all hashes and comparing against the manifest.

## Scope
- Read manifest.json from evidence export directory
- Recalculate SHA-256 for each referenced file
- Compare against manifest hashes
- Verify master hash chain
- Report pass/fail per file and overall

## Success Criteria
- [ ] Reads any valid evidence export directory
- [ ] Verifies individual file hashes
- [ ] Verifies master hash chain
- [ ] Clear pass/fail output with details
- [ ] Returns exit code 0 on pass, 1 on fail
