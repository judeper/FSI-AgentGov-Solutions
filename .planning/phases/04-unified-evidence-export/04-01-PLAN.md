# Plan 04-01: Master Evidence Export Script

## Objective
Create `Export-UnifiedComplianceEvidence.ps1` — orchestrates per-solution evidence collection into a unified compliance evidence package suitable for FINRA/SEC/OCC audits.

## Scope
- Query each Tier 2 solution's validation/violation data for configurable date range
- Export per-solution CSV + JSON evidence files
- Generate master manifest with solution inventory, record counts, hash chain
- Package into timestamped directory structure
- Support DryRun and solution filtering

## Implementation Details

### Output Directory Structure
```
evidence-export-YYYY-MM-DD/
├── manifest.json                    # Master manifest with hash chain
├── acv/
│   ├── validations.csv
│   └── violations.csv
├── ssc/
│   ├── validations.csv
│   └── violations.csv
├── aam/
│   ├── validations.csv
│   └── violations.csv
├── cmm/
│   ├── validations.csv
│   └── violations.csv
└── fus/
    ├── validations.csv
    └── violations.csv
```

### Hash Chain
- SHA-256 hash per evidence file
- Master hash = SHA-256 of concatenated file hashes (sorted alphabetically)
- Matches existing per-solution evidence export pattern

- [ ] Script exports evidence from all 5 Tier 2 solutions
- [ ] Each solution's data exported to CSV + JSON
- [ ] Master manifest.json generated with hash chain
- [ ] DryRun mode shows plan without querying Dataverse
