# Changelog

All notable changes to the Unrestricted Agent Sharing Detector are documented here.

## [1.0.0] — February 2026

### Added
- Detector scan flow (`uasd-detector-scan-agents.json`) for continuous monitoring of agent sharing configurations
- Remediation flow (`uasd-remediation-apply-sharing-policy.json`) for automated policy enforcement
- Exception approval workflow (`uasd-exception-approval-workflow.json`) for business-justified exceptions
- Exception manager app (`uasd-exception-manager-app.json`) for exception lifecycle management
- Teams adaptive card alert (`adaptive-card-uasd-alert.json`) for real-time violation notifications
- All 5 artifacts migrated from FSI-AgentGov `src/` to FSI-AgentGov-Solutions
